# Playbook Architecture

> **Slug:** `playbook` | **Status:** 🚧 draft | **Last Updated:** 2026-04-09 20:13:31 UTC

## Purpose
Document the playbook execution system and the integration points an AI coding agent needs to extend it safely.

## Scope
Includes frontend streaming behavior, backend workflow execution, gRPC stream consumption, cancellation handling, replay, evaluation, undo/redo, HITL copilot, prompt registry behavior, copilot response input handling, backend crash diagnostics, stream error-containment behavior, and ambiguous artifact routing resolution.

## UI Notes
The execution sidebar step list now shows only the step number, status, and duration in a narrower column. The step execution picker now sits beside step mode, and the step detail results view no longer shows an output heading or the "choose a specific step execution" helper text.
