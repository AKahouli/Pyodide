# Playbook Architecture

> **Slug:** `playbook` | **Status:** 🚧 draft | **Last Updated:** 2026-04-09 19:55:34 UTC

## Purpose
Document the playbook execution system and the integration points an AI coding agent needs to extend it safely.

## Scope
Includes frontend streaming behavior, backend workflow execution, gRPC stream consumption, cancellation handling, replay, evaluation, undo/redo, HITL copilot, prompt registry behavior, copilot response input handling, backend crash diagnostics, stream error-containment behavior, and ambiguous artifact routing resolution.

## Architecture
Playbook workflow execution runs through gRPC streaming calls from Nest to the ADK service. The backend buffers step updates, forwards them to the frontend over SSE, and finalizes the execution when the gRPC stream terminates.

## UI Notes
The execution sidebar step list now uses compact step-number badges instead of step titles. Each row still shows the step status icon, the agent name, and the duration, while the sidebar width is reduced.
