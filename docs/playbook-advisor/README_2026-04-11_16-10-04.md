# Playbook Advisor — Actionable Remediations

> **Slug:** `playbook-advisor` | **Status:** 🚧 draft | **Last Updated:** 2026-04-11 16:10:04 UTC

## Purpose
Document the actionable remediation system and the unified issue grouping used in the Advisor tab.

## Scope
Includes backend classification logic, preview/apply endpoints, frontend types, the `AdvisorChangeReviewDialog` component, wired CTA buttons, category badges on remediation items, grouped issue panels, localization, and integration with the existing advisor tab.

## What Changed
- Advisor findings (rewriteHints, missingFacts, incoherences, unsupportedClaims, handoffRisks, tool issues, execution summary items) are classified into structured `AdvisorRemediationItem` objects with a category badge.
- The remediation suggestions pane still comes from `rewriteHints`, but it now renders with the same badge-row style as the rest of the advisor findings.
- The issue panels below it are now grouped into dedicated badge sections instead of dense multi-column boxes.
- Categories: `structure`, `prompt`, `contract`, `handoff`, `tooling`, `evidence`, `outputFormat`
- Category inference is heuristic-based (keyword matching on the finding text) with a configurable fallback.
- The three CTA buttons in the Advisor tab now open a shared `AdvisorChangeReviewDialog` instead of mutating immediately:
  - `Update current playbook` — opens modal in `update-current` mode
  - `Optimize this step` — opens modal in `optimize-step` mode (filtered to current task)
  - `Generate new optimized playbook` — opens modal in `generate-new` mode
- The review modal supports:
  - grouped items by category with collapsible sections
  - per-item checkbox to exclude
  - per-item Edit button with inline textarea
  - Select all / Deselect all
  - selected count display
  - Apply button that sends only selected (and possibly edited) items
- Each remediation item in the Advisor tab now shows a category badge and an Apply button.
- The apply endpoint injects the selected hints into the LLM rewrite prompt so only user-approved changes are applied.

## Data Model
```ts
interface AdvisorRemediationItem {
  id: string;                    // composite: field:taskId:index
  category: RemediationCategory; // structure|prompt|contract|handoff|tooling|evidence|outputFormat
  scope: 'task' | 'playbook';
  targetTaskId: string | null;
  title: string;                 // truncated first 80 chars
  description: string;           // full text
  rationale?: string;
  editable: boolean;             // rewriteHints are editable, findings are not
  defaultSelected: boolean;      // rewriteHints default to true
  source: { kind: string; field: string; index: number };
}
```
