1Conversation 10 sub-features

Native Responses parent, faster first token, and a full files-and-artifacts surface.

Conversation moved to a native Responses parent with per-model API selection, cutting time-to-first-token and adding a live thinking indicator. Streaming and transport were hardened (HTTP/2 gateway reuse, gateway connections kept across human turns, authenticated SSE replay across replicas, fail-closed execution state). The composer gained a complete files-and-artifacts surface — expose, search, restore, delete, image history and toolbar — plus OpenUI media/slide rendering and standalone dashboard export. Concurrency and background work were made safe (concurrent replies, background tasks, clarification, fan-out recovery, lease-renewal checkpoints), and sharing/copilot handoff were gated behind audience controls and permissions.
